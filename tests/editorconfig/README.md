These glob fixtures are from [EditorConfig core tests](https://github.com/editorconfig/editorconfig-core-test); `REVISION` pins the upstream commit and `LICENSE.txt` preserves its BSD license. They run as part of `zig build test`, without downloading anything.

`prepare_cases.py` translates the upstream CMake cases to `cases.json`. The original expectations remain recorded in `upstream_expected`. Six explicit updates follow the [0.17.2 specification](https://spec.editorconfig.org/): bracket contents are literal characters, and slashes inside brackets do not anchor a section to the configuration directory. The older upstream fixtures instead interpret hyphens as ranges and bracket expressions containing a slash as literal strings. These differences are recorded, not silently skipped. This is a formatting integration, not a standalone EditorConfig CLI.
